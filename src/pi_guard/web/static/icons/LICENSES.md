# Icons

- `sprite.svg` is built from [Tabler Icons](https://tabler.io/icons) (MIT), including the outline
  brand icons for Telegram, WhatsApp, Discord, OpenAI, GitHub, Docker, Signal and X.
- Filled brand icons come from [Simple Icons](https://simpleicons.org) (CC0-1.0): Anthropic, Mistral,
  Ollama, Pi-hole, MQTT, WireGuard, Nextcloud, Paperless-ngx, DeepL, Home Assistant, Gemini,
  Raspberry Pi, Bitcoin, Monero and Litecoin.
- The icons in `android/app/src/main/res/drawable` are the same Tabler icons as vector drawables.

Brand names and logos belong to their owners. They only name the service in question here.
